Developer Keys Addendum

Every screen of Geargrave Outlands and the Ctrl+key shortcuts it answers to. On a German keyboard Ctrl is the Strg key; the game treats both names as the same thing. These shortcuts exist for designers, modders and testers. None of them is needed to play, and none of them is listed in the in-game key help.

Most of these keys change the game state at once and without confirmation. Use them on a throw-away save. A forced win, a revealed map or a granted vehicle stays in the save when you quicksave afterwards.

Title screen

KeyEffectKind
Ctrl+TOpens the towing editor, the bench that sets how a towed vehicle sits behind its tower in the convoy screen and the isometric battle. Only on the title screen; pressing a modifier alone does not start the game.tool

World map

The map screen is the hub. All of these work while no modal is open and no travel day is running.

KeyEffectKind
Ctrl+ICheat console. Five tabs: grant map resources, drop workshop items into the parts shelf, stock warehouse build parts (bp_*), add any registry vehicle to the crew, recruit any named character. Closes with Esc or Ctrl+I.debug
Ctrl+TTranslation helper. Search the live translation catalog of the base game and every loaded level, record corrected texts, and export them as a contribution file for the support repo. Closes with Esc or Ctrl+T. This is the one key also shown to players, on the EARLY ACCESS tab of the settings.feedback
Ctrl+FQuick-battle sandbox. A modal with four faction fights against a synthetic test convoy, run through the real briefing and battle flow. Second press closes the modal.debug
Ctrl+ZOpens the cutaway simulation: every vehicle type with a cutaway, full crew, damage state adjustable. Returns to the map on Esc.tool
Ctrl+COpens the cutaway tuner: seat figures, portrait discs and picture zoom per vehicle, saved to data/cutaway_tuning.json.tool
Ctrl+RDebug cartography. Marks every location of the level as known, names included, and lifts the fog. Plain R only toggles the zoom readout.debug
Ctrl+ShiftSwaps between the painted 2D map and the 3D diorama view. Pressing the second of the two modifiers toggles; the view survives scene rebuilds. Works in both directions.view
Ctrl+left click on a locationOpens that location directly, skipping the crew-position and travel gating. Works on the 2D marker and in the 3D diorama.debug
Plain keys on the map that belong to the same debug family: E opens the test-encounter launcher, F9 previews the game-over screen, Space advances the day.

Travel day KONVOI-24 chapter screen

KeyEffectKind
Ctrl+DRIVE buttonInstead of driving, opens the event picker. The chosen event replaces the random draw on arrival, so a level author can test a specific travel event without waiting for the dice.debug
Ctrl+EWhile an event board is open: opens the same picker and swaps the displayed event at once.debug
Ctrl++ / Ctrl+-While an event board is open: steps to the next or previous event in the list, for checking layout and text. Numpad keys count too.debug

Battle Roadwar screen, lane and isometric view

KeyEffectKind
Ctrl+WForced win. Ends the fight at once in the planning phase: enemies are wrecked, fled or surrendered with rolled damage, and the victory overlay appears. The log records it as debug.forcewin. Swallowed inside the simulation and tuner so they cannot "win" themselves.debug
Ctrl+ÄOpens the iso size check, the line-up of every vehicle type and obstacle for tuning relative sizes. Isometric view only, planning phase only. On a US layout the same physical key is '.tool
Ctrl+ÖCycles the isometric backdrop set: stony desert, canyon, snowy plains, snowy mountains. Landmark, snow and season looks follow. View only; the next battle picks its own set. On a US layout the same physical key is ;.view
Related plain keys in the isometric view: Home resets the free camera, 1 2 3 pick a stance card, M opens MORE ORDERS, held Space speeds up the resolution.

Loot hall

KeyEffectKind
Ctrl+VStages one captured hull of every vehicle type in the carousel, so the relative sizing of the salvage hall can be checked against the whole registry in one pass. Space steps the carousel.debug

Convoy screen

Both keys also work while the vehicle context menu is open.

KeyEffectKind
Ctrl+SWith a vehicle selected: opens the small size modal that scales the side-view sprite. The value is written to the side-view scale registry (data/sideview_scales.json) and is the default for every screen.tool
Ctrl+AALL mode: shows every vehicle type of the registry instead of the crew's convoy, for comparing sizes side by side. Second press returns to the convoy.view

War Rig builder Roadhold screen

KeyEffectKind
Ctrl+CBuild mode on or off. In build mode a module is installed into a bay from nothing, without parts or crew hands. Designer tool, not a player path.debug
Ctrl+AShowcase: every slot occupied in the tech style. View only, nothing is written.view
Ctrl+SSize modal for both side views of the rig; writes at once to the side-view scale registry. Second press closes it.tool

Rust on the Road wreck and fallen ledger

KeyEffectKind
Ctrl+PSwaps between the run's real ledger and a set of example data, for layout checks and screenshots. Press again to swap back.view

Towing editor opened with Ctrl+T on the title screen

Two columns, convoy screen and isometric battle. Tab switches the column, plain keys nudge the load (W/S spacing, arrows height, A/D rotation, +/- size, Shift multiplies by five). Results are stored in towing_offsets.json.

KeyEffectKind
Ctrl+← / Ctrl+→Previous or next tower. Plain arrows step through the loads.tool
Ctrl+LLegal loads only: filters the load list to what the tow tiers allow.tool
Ctrl+RResets the fit of both columns for this pair. Plain R resets only the current column.tool

Cutaway simulation opened with Ctrl+Z on the map

Pages through every vehicle type that has a cutaway, with a full crew. ←/→ step the vehicle, +/- change the damage state, letter keys toggle the effects listed under H. Esc returns to the map.

KeyEffectKind
Ctrl+Ä / Ctrl+ÖNot available here. The size check and the backdrop cycle are disabled while the simulation runs; other Ctrl chords are ignored.view

Cutaway tuner opened with Ctrl+C on the map

Same fleet as the simulation, with the toggles replaced by anchor editing: click a seat, then W/A/S/D move it, I/J/K/L move its head, +/- scale it, 7/9 zoom the picture, Tab cycles seats, Backspace resets the vehicle.

KeyEffectKind
Ctrl+SSaves now. The tuner also autosaves 0.6 s after the last change and when you leave.tool

Iso size check opened with Ctrl+Ä in an isometric battle

Hides the battle and lines up every vehicle type and obstacle at their isometric scale. Click an entry to open the size modal for it; the value goes to iso_scales.json. Mouse wheel and ←/→ scroll the line.

KeyEffectKind
Ctrl+Ä or EscBack to the battle.tool

Cargo deck tuner standalone scene

Not reachable from the game. Start it from the project folder with the Godot editor binary:

godot --path godot res://CargoDeckTuner.tscn

Left: carrier and cargo pickers with the deck sliders. Right: the carrier with the load on its deck; deck guides and the load can be dragged. ←/→ switch loads, +/- scale the load, G toggles guides, C opens the contact sheet.

KeyEffectKind
Ctrl+arrowsNudge the load on its deck. Shift makes the step five times larger.tool
Ctrl+SSaves data/cargo_decks.json (in exported builds to the user folder).tool
Ctrl+RReverts to the file on disk.tool

Modal dialogs

The cheat console and the translation helper are truly modal: while one is open, every unhandled key is swallowed so Space, M or R never reach the map underneath.

KeyEffectKind
Ctrl+I or EscCloses the cheat console.debug
Ctrl+T or EscCloses the translation helper.feedback

Notes for modders

  • Keys are read by key code on your layout, so Ctrl+Z is the key labelled Z even on a QWERTZ keyboard. The two umlaut chords in battle fall back to the physical key position for non-German layouts.
  • The old battle cheats (F5 win, Ctrl+K, Ctrl+D) were removed. Ctrl+W in the battle screen is the only remaining way to skip a fight.
  • Tuning files written by the benches (side-view scales, iso scales, towing offsets, cutaway tuning, cargo decks) are game data. A mod ships its own cutaway anchors through the cutaway editor; the other registries belong to the base game.
  • Image reports for support go through F10, which needs no modifier. See the EARLY ACCESS tab in the settings.
